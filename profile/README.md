<p>这篇按电脑端的操作顺序讲：先说清供应商要交付哪几项参数，再分别讲系统代理、浏览器单独绑定、带认证的客户端三种填法，然后给验证与排错方法，最后讲配置怎么固定成台账。</p>
<h2>一、先把静态IP的信息拿全</h2>
<p>开通后供应商一般给四项：服务器地址、端口、用户名、密码。少任何一项都连不上，先对齐再动手。</p>
<p>还要问清协议是 HTTP 还是 SOCKS5，两者填法不同，混填最常见的表现是端口通但网页打不开。</p>
<p>顺便确认允许几台设备同时连、是否限制长连接，这两条决定后面能不能多开。</p>
<h2>二、Windows 系统代理怎么填</h2>
<p>打开设置里的网络和 Internet，点代理，把使用代理服务器打开，地址填 IP，端口填数字，保存即可。</p>
<p>系统代理走的是 WinINET 接口，Chrome 与 Edge 默认跟随，Firefox 有自己的设置项，需要单独改。</p>
<p>填完先别关设置页，回浏览器刷新一次，确认没有弹认证框再继续往下配。</p>
<h3>系统代理覆盖不到的地方</h3>
<p>Java 程序、部分游戏客户端、自带网络栈的工具会绕过系统代理，这类程序要在自身配置里单独指定。</p>
<h2>三、浏览器单独绑一条线路</h2>
<p>想让浏览器和系统走不同出口，可以给 Chromium 内核加启动参数，指定代理地址和端口。</p>
<p>做法是复制一个快捷方式，在目标后面加参数，改个名字，双击它就只让这个窗口走代理。</p>
<p>一个店铺配一个快捷方式加一条固定 IP，登录记录不会互相串，这是最省事的隔离方式。</p>
<h2>四、带账号密码时改用客户端</h2>
<p>HTTP 代理需要认证时，系统代理框填不了用户名，得靠按进程分流的工具来接管。</p>
<p>规则里把要走的程序加进去，动作设为代理，其余保持直连，匹配顺序从上往下。</p>
<p>静态 IP 是独享的，客户端里关掉自动切换和故障转移，避免中途换到别的出口。</p>
<h3>代理是否真的生效</h3>
<p>打开任意 IP 查询页，看出口地址是否等于供应商给的地址，再看时区和语言是否跟着变。</p>
<p>命令行加代理参数请求一个固定网址，返回 200 且内容正常，说明链路和认证都没问题。</p>
<h2>五、连不上怎么排</h2>
<p>第一步在本机测端口，端口不通属于网络层或白名单问题，先找供应商确认地址是否已放行。</p>
<p>第二步看协议，SOCKS5 填成 HTTP 会表现为握手失败，改回来即可。</p>
<p>第三步看认证，密码里带特殊符号要原样粘贴，前后多一个空格都会返回 407。</p>
<h2>六、把配置固定下来</h2>
<p>调通之后导出客户端配置和浏览器配置文件，换机器直接导入，比手填稳得多。</p>
<p>做一张台账，记 IP、端口、绑定店铺、启用日期和到期日，续费前能一眼对上。</p>
<p>到期前一周处理续费，断线期间不要做改密码、改收款这类操作。</p>

<h2>常见问答</h2>
<h3>静态IP和动态IP在电脑上的设置方法一样吗？</h3>
<p>答：填写位置一样，都是地址加端口。区别在稳定性，静态 IP 地址长期不变，填一次能用很久；动态 IP 每次连接可能换地址，要用提取链接在客户端里动态获取，不能写死。</p>
<h3>系统代理开了，为什么有的软件还是走本地网络？</h3>
<p>答：系统代理只对调用 WinINET 接口的程序生效。Java 应用、部分游戏客户端和自带网络栈的工具会绕过它，需要在程序内部单独设置，或用按进程分流的客户端接管。</p>
<h3>一个美国静态IP能同时登几个店铺？</h3>
<p>答：技术上可以同时连，但同一出口下的账号会共享网络画像。常见做法是一个店铺对应一条固定 IP，总量按店铺数上浮两成留冗余，具体以平台规则和自身管理能力为准。</p>
<h3>电脑配好之后手机还要再设一次吗？</h3>
<p>答：要。电脑的系统代理不会同步到手机，手机需要在 Wi-Fi 高级设置里单独填代理，或者装支持代理的客户端，两边是各自独立的配置。</p>
